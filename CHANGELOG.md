# Changelog

This file records notable project changes. There are no tagged releases or released versions documented in the repository as of this writing. The package metadata currently declares version `0.1.0`; that does not by itself indicate a published release.

## Unreleased

- Added bounded, read-only static analysis for explicitly authorized local files and directories.
- Added SHA-256 acquisition provenance, signature-family identification, byte profiling, and strict text-encoding validity hints.
- Added an offline loopback browser interface and optional local SQLite report persistence.
- Added native installer packaging for Debian/Ubuntu, Arch Linux, Windows, and macOS; CI provides build artifacts rather than publishing GitHub Releases.
