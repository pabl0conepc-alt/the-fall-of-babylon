# Code of Conduct

## Our standards

Participants are expected to treat one another with respect and keep discussions constructive. Examples of behavior that contributes to a welcoming community include:

- Being considerate and respectful of differing viewpoints and experiences.
- Giving and receiving constructive feedback professionally.
- Focusing criticism on ideas and work, not on people.
- Respecting privacy and sharing only material that you are authorized to disclose.

Unacceptable behavior includes harassment, personal attacks, discriminatory or sexualized language, publishing another person's private information without permission, and other conduct that would reasonably make participation unsafe or hostile.

## Scope and enforcement

This code applies in project spaces, including issues, pull requests, and other project discussions. Project maintainers may remove or edit contributions and may limit participation when necessary to address behavior that violates this code.

If you experience or witness unacceptable behavior, report it privately through a GitHub channel available to you. Do not include private or sensitive information in a public issue. This repository does not document a dedicated conduct-reporting contact.
